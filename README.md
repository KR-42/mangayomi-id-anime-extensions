## 🛠️ Pasang Manual

<details open>
<summary><b>Langkah pasang (ketuk untuk buka/tutup)</b></summary>

<br/>

1. Buka **Mangayomi** → **Browse / Jelajahi** → tab **Ekstensi** → **Anime**.
2. Ketuk ikon **tambah (➕)** / **Extension repos**.
3. Tempel URL index berikut:

   ```text
   https://raw.githubusercontent.com/KR-42/mangayomi-id-anime-extensions/main/anime_index.json
   ```

4. Konfirmasi, lalu pilih sumber yang ingin dipasang → ketuk **Install / Pasang**.
5. Sumber muncul di tab **Anime** dan siap dipakai. 🎉

</details>

<details>
<summary><b id="domain-berubah">🌐 Domain situs berubah? (ketuk)</b></summary>

<br/>

Situs anime Indonesia sering pindah domain. Kamu **tidak perlu** install ulang:

1. **Ekstensi → Anime → (nama sumber) → Pengaturan sumber**.
2. Isi **Domain situs** dengan domain baru (tanpa `/` di akhir), misalnya `https://situs-baru.example`.
3. Kosongkan lagi untuk kembali ke domain bawaan.

Link di perpustakaan disimpan **relatif**, jadi ganti domain **tidak** menghilangkan daftar anime yang kamu ikuti. Khusus **Anoboy** & **Animangahub** ada pula dropdown domain siap-pilih.

Kalau ekstensi tetap rusak setelah situsnya pindah domain, misalnya domain baru punya tampilan yang berbeda, [**lapor bug**](https://github.com/KR-42/mangayomi-id-anime-extensions/issues/new) atau minta di [**Discussions**](https://github.com/KR-42/mangayomi-id-anime-extensions/discussions) supaya ekstensinya diperbarui ke domain baru.

</details>

<a id="download"></a>

## ⬇️ Fitur Download

> [!NOTE]
> Unduhan memakai **tombol unduh bawaan Mangayomi** di daftar episode. **Semua sumber sudah bisa mengunduh** (diuji di HP pada 23 Nov 2026) ✅

- **Kualitas mana yang diunduh?** Mangayomi tidak menanyakan kualitas saat mengunduh; ia mengambil video **teratas** di daftar. Urutan itu mengikuti **Pengaturan sumber → Kualitas yang diutamakan** (bawaan: tertinggi dulu). Mau unduhan lebih hemat kuota? Hilangkan centang 1080p/720p sebelum mengunduh.
- Mangayomi selalu mendahulukan file **.mp4** daripada stream HLS. Di **Otaku Desu** mirror .mp4 umumnya 720p (sebagian episode juga punya 480p), jadi unduhan biasanya **720p** walau kamu memilih 360p.

**Server yang dipakai saat mengunduh:**

| 🎬 Sumber | ⬇️ Server unduhan | ⚡ Kecepatan (terukur) | 📝 Catatan |
|:---|:---|:---:|:---|
| **Otaku Desu** | Mirror .mp4 (archive.org dll.) | — | Umumnya 720p. |
| **Samehadaku** | VIP STREAMING (Filedon), Wibufile | — | Sampai 1080p. Episode yang hanya punya Blogger: 🐢 ±12 menit. Episode lama yang hanya gdriveplayer/Mega: tidak bisa. |
| **AnimeIndo** | CEPAT (HLS) | 🟢 ±10 MB/s | Mengikuti Kualitas yang diutamakan. |
| **Nonton Anime ID** | File .mp4 situs | — | |
| **Anibatch** | BerkasDrive, HiAnime | 🟢 ±2 MB/s | Sampai 1080p. Sebagian 1080p berformat MKV, tetap bisa diputar. HiAnime ikut mengunduh subtitle Indonesia. |
| **Kuronime** | Mp4Upload dll. | — | |
| **Oploverz** | Abyss (.mp4), Upbolt (HLS) | 🐢 1080p lambat | Abyss 1080p bisa ±10–20 menit per episode. **Disarankan 720p ke bawah.** |
| **Anoboy** | YourUpload | 🟢 ±3 MB/s | Episode yang hanya punya Blogger: 🐢 ±12 menit. |
| **Animangahub** | Filedon dll. | — | |

**Kenapa ada yang lambat?** Mangayomi mengunduh satu episode per sumber dengan satu koneksi.
Server Abyss (Oploverz) dan Blogger (Google) membatasi kecepatan per koneksi, jadi ini tidak bisa
dipercepat dari ekstensi. Streaming tidak terpengaruh.

- Ganti pengaturan berlaku untuk **semua** episode dan juga kualitas saat menonton.

## ⚖️ Disclaimer

> [!IMPORTANT]
> ### ❤️ Tetap dukung situs streaming aslinya
> Ekstensi ini hanyalah **pembaca** halaman yang sudah publik. Para fansubber dan situs sumber bekerja keras (dan hidup dari iklan di situsnya). **Tolong tetap kunjungi dan dukung situs streaming aslinya** — matikan adblock untuk mereka, atau tonton langsung di webnya dari waktu ke waktu. Tanpa mereka, tidak ada anime sub Indo untuk kita semua. 🙏

- Proyek ini **tidak berafiliasi** dengan Mangayomi maupun situs anime mana pun.
- Ekstensi **hanya membaca & mengurai halaman publik**. Tidak **menyimpan, menyalin, atau mendistribusikan** konten berhak cipta, dan tidak melewati paywall/login.
- Ekstensi **tidak** memuat iklan dan **tidak** memblokir iklan di situs sumber.
- Semua konten milik pemegang hak masing-masing. **Pengguna bertanggung jawab penuh** atas penggunaan sesuai hukum di wilayahnya.
- Gunakan secara wajar — jangan membanjiri situs sumber dengan permintaan berlebihan.

<details>
<summary><b>🔒 Soal Cloudflare & iklan (teknis)</b></summary>

<br/>

Ekstensi **tidak** memuat iklan dan **tidak** membobol proteksi situs sendiri:

- URL stream diambil dari balik halaman embed, jadi player beriklan tidak dirender.
- Tantangan Cloudflare diselesaikan oleh **aplikasi Mangayomi** (WebView bawaan / FlareSolverr / Byparr), bukan oleh ekstensi.
- Player ter-obfuscate dibuka memakai **ekstraktor native** aplikasi, bukan kode ekstraksi yang disalin ke repo ini.

</details>

<details>
<summary><b>👩‍💻 Untuk developer</b></summary>

<br/>

```bash
npm install
npm run build      # inline src-shared/ ke javascript/anime/src/id/
npm run generate   # tulis ulang anime_index.json
npm run check      # lint + validate + test harness
npm run test:live  # jalankan test yang sama ke situs asli
```

Jangan edit `javascript/anime/src/id/*.js` langsung — itu hasil `npm run build`.
Panduan menambah sumber: [`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md).

</details>
