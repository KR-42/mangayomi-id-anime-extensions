> Hanya sumber yang punya catatan yang ditulis. Sumber yang tidak tercantum = **belum ada masalah yang diketahui** (AnimeIndo, Kuronime, Anoboy).

| 🎬 Sumber | 🐛 Catatan / Masalah |
|:---|:---|
| **Otaku Desu** | Episode kadang lambat dibuka — **tunggu 1–2 menit** dulu. Kalau belum jalan, **ganti server stream**. Kalau semua server tetap gagal **setelah lebih dari 2 menit**, silakan [laporkan bug](#-feedback--lapor-bug). |

| **Oploverz** | Server **upbolt** kadang minta verifikasi Cloudflare — tekan **WebView** di layar error sekali, lalu buka episode lagi. |

Server **1 dan 2** (playmogo/plamogo) mati di sisi situs — bukan bug ekstensi, pakai **Server 3** (streampoi) kalau ada. ## 🛠️ Pasang Manual

<details open>
<summary><b>Langkah pasang (ketuk untuk buka/tutup)</b></summary>

<br/>

1. Buka **Mangayomi** → **Browse / Jelajahi** → tab **Ekstensi** → **Anime**.
2. Ketuk ikon **tambah (➕)** / **Extension repos**.
3. Tempel URL index berikut:

   ```text
   https://raw.githubusercontent.com/KR-42/mangayomi-id-anime-extensions/main/anime_index.json
   ```

4. Konfirmasi, lalu pilih sumber yang ingin dipasang → ketuk **Install / Pasang**.
5. Sumber muncul di tab **Anime** dan siap dipakai. 🎉

</details>

<details>
<summary><b id="-domain-berubah">🌐 Domain situs berubah? (ketuk)</b></summary>

<br/>

Situs anime Indonesia sering pindah domain. Kamu **tidak perlu** install ulang:

1. **Ekstensi → Anime → (nama sumber) → Pengaturan sumber**.
2. Isi **Domain situs** dengan domain baru (tanpa `/` di akhir), misalnya `https://situs-baru.example`.
3. Kosongkan lagi untuk kembali ke domain bawaan.

Link di perpustakaan disimpan **relatif**, jadi ganti domain **tidak** menghilangkan daftar anime yang kamu ikuti. Khusus **Anoboy** & **Animangahub** ada pula dropdown domain siap-pilih.

</details>

## ⚖️ Disclaimer

> [!IMPORTANT]
> ### ❤️ Tetap dukung situs streaming aslinya
> Ekstensi ini hanyalah **pembaca** halaman yang sudah publik. Para fansubber dan situs sumber bekerja keras (dan hidup dari iklan di situsnya). **Tolong tetap kunjungi dan dukung situs streaming aslinya** — matikan adblock untuk mereka, atau tonton langsung di webnya dari waktu ke waktu. Tanpa mereka, tidak ada anime sub Indo untuk kita semua. 🙏

- Proyek ini **tidak berafiliasi** dengan Mangayomi maupun situs anime mana pun.
- Ekstensi **hanya membaca & mengurai halaman publik**. Tidak **menyimpan, menyalin, atau mendistribusikan** konten berhak cipta, dan tidak melewati paywall/login.
- Ekstensi **tidak** memuat iklan dan **tidak** memblokir iklan di situs sumber.
- Semua konten milik pemegang hak masing-masing. **Pengguna bertanggung jawab penuh** atas penggunaan sesuai hukum di wilayahnya.
- Gunakan secara wajar — jangan membanjiri situs sumber dengan permintaan berlebihan.

<details>
<summary><b>🔒 Soal Cloudflare & iklan (teknis)</b></summary>

<br/>

Ekstensi **tidak** memuat iklan dan **tidak** membobol proteksi situs sendiri:

- URL stream diambil dari balik halaman embed, jadi player beriklan tidak dirender.
- Tantangan Cloudflare diselesaikan oleh **aplikasi Mangayomi** (WebView bawaan / FlareSolverr / Byparr), bukan oleh ekstensi.
- Player ter-obfuscate dibuka memakai **ekstraktor native** aplikasi, bukan kode ekstraksi yang disalin ke repo ini.


</details>
